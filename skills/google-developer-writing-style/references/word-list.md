# Word list (high-frequency entries)

Condensed from the Google developer documentation style guide word list (CC BY 4.0), https://developers.google.com/style/word-list. For terms not here, check the live list, then Merriam-Webster (use the first listed spelling, for example *canceled*).

| Avoid | Use instead / rule |
|---|---|
| above, below (position in doc) | *preceding*, *earlier*; *following*, *later* |
| above / higher (versions) | *later* ("2.2 or later") |
| below / lower (versions) | *earlier* |
| abort | *stop*, *cancel*, *exit*, *end* |
| access (verb) | *see*, *edit*, *find*, *use*, *view* when possible |
| aka | *also known as*, or a parenthetical |
| allows you to, enables you to | *lets you* |
| and/or | "A, B, or both" (OK in tight table cells) |
| as (meaning because) | *because* |
| as of this writing, at present, currently, presently | delete |
| best effort | describe what actually happens |
| blacklist / whitelist | *denylist*, *allowlist* (nouns only, not verbs); or describe the action |
| blast radius | *affected area* |
| cellphone, smartphone | *mobile phone*, *phone*, *mobile device* |
| check (a checkbox) | *select* |
| check box | *checkbox* |
| click here | descriptive link text |
| click on | *click* |
| comprise | *consist of*, *contain*, *include* |
| config (prose) | *configuration* |
| could | *can* (or *might* for possibility) |
| Create a new… | *Create a…* |
| data are | *data is* (mass noun: *less data*) |
| data base, datacenter, file name, host name | *database*, *data center*, *filename*, *hostname* |
| deprecated (meaning removed) | *removed*, *deleted*, *shut down* |
| deselect, uncheck (checkbox) | *clear* (*deselect* is fine for other UI elements) |
| desire, desired | *want*, *need* |
| disable (meaning broken) | *broken*, *unavailable*; for settings: *turn off* or *disable*, consistently |
| display (intransitive) | *appear*, *is displayed* |
| does not yet | delete *yet* |
| drop-down (noun) | *list*, *menu* |
| dummy | *placeholder* |
| e.g. | *for example*, *such as* |
| easy, easily, simple, simply, quick, quickly | delete |
| e-mail | *email* (not a verb: *send email*) |
| etc., and so on | introduce with *such as* / *including* |
| eventually, soon, in the future | delete; don't pre-announce |
| execute | *run* |
| first-class | describe the specific capability |
| for instance | *for example* |
| grayed out | *unavailable* |
| guys | *everyone*, *folks* |
| hang, hung | *stop responding*, *not responding* |
| he/she, (s)he | *they* |
| hit | *click*, *press*, *type* |
| hover | *hold the pointer over*, *point to* |
| i.e. | *that is* |
| impact (verb) | *affect* |
| in order to | *to* (keep only if needed for clarity) |
| ingest (simple copy) | *import*, *load*, *copy* |
| just | delete, or *only* |
| key (adjective, "key point") | *important*, *main* |
| kill | *stop*, *end* (except Linux signals) |
| latest, new, newer, now, old, older | delete, or give a version/date reference |
| learnings | *lessons*, *what you learned* |
| leverage | *use*, *build on*, *take advantage of* |
| let's | rewrite in second person |
| log in, login (verb) | *sign in* (unless the UI says log in) |
| man-hours, manpower, manned | *person-hours*, *staff*, *staffed* |
| master / slave | *primary*/*replica*, *controller*/*worker*, and similar |
| may (possibility) | *might*; *can* for permission |
| native (feature) | *built-in* |
| once (meaning after) | *after* |
| on-premise, on-prem | *on-premises* |
| per (outside rates) | *according to*, *for each* |
| performant | a precise word (*fast*, *efficient*, *accurate*) |
| please, please note | delete (*please* is OK only when asking permission or forgiveness) |
| pop-up | *dialog* or *menu* |
| proper, properly | describe the technical condition |
| pros / cons | *advantages* / *disadvantages* |
| regex | *regular expression* |
| repo | *repository* |
| sanity check | *quick check*, *confidence check* |
| scale (alone, "at scale") | say the direction or magnitude |
| setup (verb) | *set up* (noun/adjective: *setup*) |
| should | *must*, or "We recommend…" (OK for widely recognized advice) |
| since (meaning because) | *because* |
| sign into | *sign in to* |
| spin up | *create*, *start* |
| this article, this topic, this page (the doc) | *this document* |
| utilize | *use* |
| via | *through*, *by using* |
| wish | *want* |
| will, would (result of an action) | present tense |
| existing | delete, or be specific (timeless rule) |
| possible / impossible (meaning can / can't) | *you can*, *you can't* |
| vice versa | rewrite with both directions stated |
| vs. | *versus* |
| while (meaning although) | *although* |
| with (meaning has) | *that has* |
| each (meaning all) | *all*, or *every* |
| review (meaning read) | *read* |

## Spelling and compounds

- One word: *backend*, *frontend*, *codebase*, *checkbox*, *endpoint*, *filename*, *hostname*, *hardcode*/*hardcoded*, *lifecycle*, *runbook*, *ecommerce*, *healthcare*, *namespace*, *screenshot*, *email*, *datastore*.
- Two words: *data center*, *data type*, *data source*, *file system*, *name server*, *home screen*.
- Hyphenated: *read-only*, *right-click*, *double-click*, *key-value pair*, *on-premises*, *pre-existing*, *big-endian*, and every *self-* and *cross-* compound.
- Noun vs. verb or adjective: *setup* / *set up*; *login* / *log in* (prefer *sign in*); *failover* / *fail over*; *runtime* (environment) vs. *run time* (when it happens); *high availability* (noun) / *high-availability* (adjective); *third party* (noun) / *third-party* (adjective).
- *internet* lowercase; *ID* not *Id*; *OAuth 2.0*; *HTTPS*; *Markdown* capitalized.
- *(Skill additions, standard English but not in the guide's list)*: *backup* (noun) / *back up* (verb); *OK* in caps; *dataset* as one word (the guide itself uses both *dataset* and *data set*; pick one and stay consistent).
- Plurals: *indexes*, *appendixes*, *matrixes* (unless math or finance context prefers *indices*, *matrices*).
