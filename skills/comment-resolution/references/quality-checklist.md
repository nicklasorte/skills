# Acceptance checklist

- [ ] Original workbook remains intact; output is a separate XLSX.
- [ ] Sheet names, headers, column order, formulas, styles, and original agency entries preserved.
- [ ] Report revision verified; Section/Page/printed Line anchors checked against supplied PDF.
- [ ] Each disposition grounded in evidence and authorized decision rules.
- [ ] Duplicate/related comments treated consistently.
- [ ] Every accepted Resolution is exact, standalone, report-ready prose; edit location and operation recorded.
- [ ] Rejected Resolution cells blank unless governing matrix instructions differ.
- [ ] Pending decisions marked, with blocker identified and no invented final text.
- [ ] Technical values, units, assumptions, references, and cross-row conflicts checked.
- [ ] Counts, blockers, and verification limits summarized.
